# Мы Рядом (Ryadom)

**Бесплатно. Open source. Без комиссий.**

Android-first Flutter-приложение для быстрой **локальной** помощи рядом.

Не маркетплейс и не «заработок на курьерах». Смысл простой:

1. человек создаёт запрос о помощи
2. люди рядом видят его на **радаре**
3. кто-то откликается
4. автор выбирает помощника
5. они координируются в приватном чате
6. помощь завершается; оценка остаётся необязательной

**Людям надо помогать.** Приложение — инструмент для этого, не бизнес-модель.

## Стек

| | |
|--|--|
| UI | Flutter (Material 3) |
| Платформа | Android first |
| Связь | Nostr: публичные события запросов/откликов + NIP-17/NIP-59 private chat |

## Возможности MVP

- Радар с зонами близости и обновлением гео
- Создание запроса, отклик и выбор помощника
- Приватный чат: NIP-17 rumor → NIP-59 seal/gift wrap, NIP-44 encryption
- Точная геопозиция — только по явному действию автора и только в приватном чате после выбора помощника
- Завершение помощи и необязательная оценка
- Радиус поиска 500 м … 10 км
- Ориентир приблизительной зоны в Яндекс / Google Картах
- Темы: классическая, ночная, светлая, киберпанк
- Блокировка, жалоба и локальный rate limit откликов

## Приватность коротко

- точные координаты не публикуются в открытых событиях запроса
- расшифрованный чат не сохраняется в `SharedPreferences`
- Nostr private key хранится через secure storage
- relay видит сетевое соединение и внешний NIP-17 gift-wrap; ограничения описаны в [PRIVACY.md](PRIVACY.md)

## Два телефона

1. Один relay Nostr на обоих телефонах.
2. Гео включено, радиусы сопоставимы.
3. A создаёт запрос.
4. B видит запрос и откликается.
5. A выбирает помощника.
6. Оба переходят в приватный чат.
7. A при необходимости отдельно передаёт точную точку.
8. После помощи A завершает запрос и при желании оставляет оценку.

Подробнее: [docs/two_phone_test_flow.md](docs/two_phone_test_flow.md)

## Участие

Issues и pull request приветствуются.

- перед PR: `flutter test` и `flutter analyze lib test`
- не присылайте `key.properties`, keystore, приватные ключи Nostr
- крупные идеи лучше сначала обсудить в issue
- уязвимости — по правилам [SECURITY.md](SECURITY.md)

## Принципы

- помощь > монетизация
- приблизительная гео-зона, не «точка у двери»
- точная точка — только осознанно и приватно
- один ясный следующий шаг на экране
- спокойный интерфейс, без протокольного шума
