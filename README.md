# Ryadom

`Ryadom` is an Android-first Flutter application for fast, local, human-centered help.

It is not a gig marketplace. The product core is simple:

- someone creates a request for help
- nearby people see it
- one person responds
- the request owner selects a helper
- the task gets completed

## MVP focus

- speed
- clarity
- reliability

The first version intentionally avoids heavy logic and extra layers. Project docs live in [docs/README.md](docs/README.md), with the MVP scope in [docs/mvp.md](docs/mvp.md).

## Stack

- Flutter
- Android first
- Nostr backend in the next integration step

## Run locally

```bash
flutter pub get
flutter run
```
