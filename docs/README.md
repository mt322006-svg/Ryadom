# Ryadom Docs

This folder is the working memory of the project.

We use it to keep the product clear, decisions visible, and context stable between sessions.

## Core docs

- [vision.md](vision.md): why `Ryadom` exists and what kind of product it should become
- [mvp.md](mvp.md): the first version boundaries
- [product_principles.md](product_principles.md): rules that protect the product from complexity drift
- [ui_radar_concept.md](ui_radar_concept.md): the current direction for the main screen and interaction model
- [decisions.md](decisions.md): important decisions and why we made them
- [session_log.md](session_log.md): short chronological log of what changed and what matters next

## How we use docs

- record decisions early
- keep docs short and honest
- prefer one strong note over many vague notes
- update the relevant doc when the product direction changes
- use the session log to avoid losing context between work sessions
