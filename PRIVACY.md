# Privacy

`Мы Рядом` работает с геолокацией и приватной перепиской, поэтому правила здесь намеренно простые и проверяемые по коду.

## Что публикуется

Публичный запрос может содержать:

- текст запроса
- приблизительную зону
- примерное расстояние на стороне клиента
- время, срочность и тип компенсации
- состояние запроса

Публичный request event **не должен содержать точные latitude/longitude**.

Приблизительная зона формируется coarse bucket-ом. Это не обещание полной анонимности: район и содержание самого запроса всё равно могут дать контекст.

## Точная геопозиция

Точная точка не отправляется автоматически.

Она может быть передана только:

1. автором собственного запроса
2. после выбора конкретного помощника
3. отдельным действием в приватном чате
4. после явного предупреждения и подтверждения

Перед отправкой приложение получает свежую координату. Payload идёт внутри зашифрованного NIP-17 сообщения.

## Приватный чат

Чат использует NIP-17/NIP-59:

- kind 14 rumor
- NIP-44 encrypted kind 13 seal
- NIP-44 encrypted kind 1059 gift wrap с одноразовым wrapper key

Это скрывает реального отправителя, request metadata и текст сообщения внутри внешнего relay event.

Relay всё ещё может видеть:

- IP/сетевое соединение клиента
- сам факт обращения к relay
- внешний kind 1059
- pubkey получателя в `p` tag gift wrap

Поэтому NIP-17 повышает приватность, но не делает сеть магически анонимной.

## Локальное хранение

- Nostr private key хранится через platform secure storage.
- Расшифрованный chat history не сохраняется в `SharedPreferences`.
- Exact-location payload не сохраняется туда в открытом виде.
- При обновлении старые plaintext chat records из прежнего snapshot удаляются.
- Публичные запросы, их состояние и локальные служебные данные могут сохраняться на устройстве.

Encrypted sender-copy сообщения публикуется через NIP-17, чтобы историю можно было восстановить из relay без общего plaintext snapshot.

## Аналитика и реклама

В MVP нет рекламного SDK и отдельного SDK пользовательской аналитики.

Это описание относится к коду этого репозитория. Сторонние relay, магазины приложений и ОС устройства имеют собственные политики.

## Контроль пользователя

Пользователь может:

- не включать геолокацию
- менять радиус
- не отправлять точную точку
- заблокировать участника
- пожаловаться
- не ставить оценку после помощи
